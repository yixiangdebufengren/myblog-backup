# 歌唱合集 · 使用说明

这个文件夹是整个「我们的歌唱合集」功能的全部文件，改歌单只需要动 `songs.yml`。

## 加一首新歌（3 步）

**1. 把音频放进 `source/audios/singing/`**

```
source/audios/singing/新歌名.mp3
```

**2. 在 `songs.yml` 末尾追加一段**

```yaml
- title: 新歌名
  by: 演唱者
  file: /audios/singing/新歌名.mp3
  size: 1.2 MB
  type: MP3
  note: 标准录音 13        # 可选，不要就删掉这行
```

`size` 是写给人看的文字，随便写 `346 KB` / `2.0 MB` 都行，不影响播放。
`type` 影响浏览器解析，MP3/M4A 两种最稳。

**3. 重新生成**

```bash
npx hexo clean && npx hexo generate
```

写文章时只需要一行：

```
{% songlist %}
```

卡片列表和牌堆模式会自动读同一份数据，条数、顺序都同步，不用改文章。

## 文件说明

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `songs.yml` | 歌曲数据 | ✅ 加歌只改这里 |
| `singing-card.css` | 卡片 + 牌堆样式 | 只有改外观才动 |
| `singing-stack.js` | 牌堆模式交互 | 只有改交互才动 |
| `README.md` | 本说明 | 不用 |

## 两种模式

点正文上方的「🎴 牌堆模式」按钮切换：

- **列表模式**（默认）：每首歌一张卡片，各自带播放器，适合找特定一首
- **牌堆模式**：大卡片叠放，左右拖拽/滑动切换，划走的卡片回到牌堆底部

牌堆模式右上角有「🔀 随机 / 🔢 顺序」小开关：

- **随机**：每次进入都打乱顺序
- **顺序**：严格按 `songs.yml` 里的排列

键盘 `←` `→` 也能切换（桌面端）。

## 关于发布

`_songs` 是下划线开头，Hexo 默认**不会**把它复制到 `public/`。
实际发布由根目录的 `scripts/songlist.js` 处理：

- 注册 `{% songlist %}` 标签，读取 `songs.yml` 渲染静态 HTML
- 把 `singing-card.css`、`singing-stack.js` 发布到 `public/songs/` 下

删掉 `scripts/songlist.js` 会导致这个功能整体失效。

## 已知限制

- 牌堆模式同屏只渲染 3 张牌（性能考虑），12 首以上也不会卡
- 拖动时若手指垂直移动，会交还给页面滚动，不会误触发切换
- 卡片内的播放器是浏览器原生控件，无法跟着卡片一起旋转，这是浏览器限制
